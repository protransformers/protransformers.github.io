The problem

Attention is a weighted average, and averages break easily.

Each attention output is a weighted mean of value tokens. In statistics terms it's a weighted least-squares estimator, and least squares has a breakdown point of zero: one bad token can drag the output anywhere.

Adversarial attacks exploit exactly this. A few swapped words, an invisible pixel pattern, a gibberish jailbreak suffix or a handful of fake graph edges each inject a token that pulls the representation off course, layer after layer.

Vanilla attention = weighted least squares
ProAttention = robust estimator
Solved in K ≤ 3 Newton-IRLS steps

With ρ = ℓ₁, Huber or MCP, tokens far from the consensus get down-weighted automatically, so outliers stop steering the output.

Why it works for images

ViT splits an image into 16×16 patches and attends over them. A PGD perturbation pushes a few patch embeddings far away from the rest, and vanilla attention averages them in. ProAttention sees those patches as outliers relative to the other patches and down-weights them in every layer.

Toy view: the red patches are perturbed. Hover over the grid to watch ProAttention down-weight them; vanilla attention keeps every weight uniform.

Adversarial edges vs. GAT
Toy illustration: the target node T aggregates its neighbours. Add adversarial edges to nodes from another class and watch which class each model predicts. GAT flips after 3 fake edges. Pro-GAT holds until the attacker's edges outnumber the true ones, which is where any robust estimator has to give in.

Get started

Three lines to a robust model

  1. Install from PyPI with pip install protransformers.
  2. Load any supported checkpoint from protransformers instead of transformers.
  3. Switch on ProAttention with set_pro_attention. That's all.
Cost

BERT inference on AG News goes from 6.1 ms to 11.7 ms with K = 2. That's about 1–2× the backbone's time, and nothing extra at training time.

Quick-start guide PyPI
robust_bert.py
from protransformers import (
    AutoModelForSequenceClassification, set_pro_attention
)

model = AutoModelForSequenceClassification.from_pretrained(
    "textattack/bert-base-uncased-ag-news"
)

# Plug in ProAttention: no retraining, same weights
set_pro_attention(model, norm="MCP", gamma=4.0, L=3)

# LLMs: load with attn_implementation="eager"
# Vanilla again: set_pro_attention(model, norm="L2")
